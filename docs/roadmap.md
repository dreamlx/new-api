# New API 外部用户系统路线图

## 项目概述

本路线图记录 New API 外部用户系统的功能规划、优化计划和技术债务，确保项目的可持续发展和与上游开源项目的兼容性。

## 🎯 当前状态 (v2.1)

### ✅ 已完成功能
- [x] 基础外部用户API体系
- [x] 用户同步、充值、Token管理
- [x] 微信小程序集成方案设计
- [x] OpenID账号统一策略
- [x] 完整的API文档和测试指南
- [x] curl测试用例覆盖

### 🚧 当前技术栈
- **后端**: Go + Gin + GORM
- **数据库**: MySQL/PostgreSQL/SQLite
- **认证**: External User ID Mapping
- **计费**: $1 USD = 500,000 quota
- **文档**: Markdown + curl示例
