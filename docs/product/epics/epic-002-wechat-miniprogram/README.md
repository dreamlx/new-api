## 📋 Epic概述

### 业务背景
需要支持微信小程序用户登录和统一账号管理。用户可能在多个平台（网站、小程序、公众号）登录，需要确保账号统一性和数据一致性。

### 业务价值
- ✅ 支持微信小程序用户无缝接入
- ✅ 多平台账号统一，提升用户体验
- ✅ 为未来UnionID统一预留扩展空间

### 成功指标
- **账号统一率**: 100% (同一OpenID只对应一个账号) ✅
- **登录成功率**: >99% ✅
- **数据一致性**: 100% (跨平台余额同步) ✅

## 🎯 核心设计

### 账号统一解决方案
基于用户期望的统一账号体验，设计了**OpenID优先匹配策略**：

#### 核心逻辑
- **OpenID唯一性**: 同一微信OpenID只能对应一个New API用户账号
- **首次优先**: 谁先注册，谁是主账号，后续登录自动统一
- **平台透明**: 各平台保持独立的external_user_id，但指向相同用户数据
- **渐进式**: 为未来UnionID统一预留扩展空间

### 技术约定
- **external_user_id格式**: `wx_mini_{openid}` 用于小程序用户
- **username格式**: `wx_user_{openid_suffix}` 取后8位
- **统一响应**: API返回`is_unified`标识账号统一状态

## 🔍 关键技术点

### OpenID优先匹配流程
```
1. 检查external_user_id是否已存在
   → 已存在：更新用户信息，返回现有账号
   → 不存在：继续第2步

2. 检查wechat_openid是否已存在
   → 已存在：
     - 更新该用户的external_user_id
     - 返回统一账号，标记is_unified=true
   → 不存在：创建新用户
```

### 数据更新策略
- **显示名称**: 仅在当前为空时更新（保护用户自定义）
- **手机号**: 仅在当前为空时更新
- **UnionID**: 无条件更新（确保最新数据）
